# 构建与分发（无 Mac 环境）

本工程不需要本地 Xcode：源码用 `clang + iPhoneOS SDK` 直接编译（`build/Makefile`），
在 GitHub Actions 的 `macos-14` runner 上完成 **编译 → ldid 签名 → 打包 .tipa → 校验**。

## 1. 触发

- 手动：仓库 → **Actions** → `build-tipa` → **Run workflow**
- 自动：push 到 `main` 或 `master`

## 2. 流水线阶段（`.github/workflows/build-tipa.yml`）

| 步骤 | 内容 |
|---|---|
| 工具链信息 | `sw_vers` / `xcodebuild -version` / iPhoneOS SDK 路径 / `python3 --version` |
| 安装 ldid | `brew install ldid`，失败则回退 `codesign --sign -` |
| 编译 | `make -C build all`（CodexApp 主程序 + ca-filetool 工具 + MTShareExtension，并装配 bundle） |
| 签名 | `make -C build sign`（entitlements 逐项对齐原包，见 `MTAgent/ResignEntitlements/`） |
| 打包 | `make -C build package` → `build/MT-Agent-replica.tipa` |
| 校验 | `verify/verify_parity.py`、`verify/verify_literals.py`、`verify/verify_package.py`、`scripts/run_all_checks.py`、`scripts/check_sources.py`、`scripts/check_conflicts.py`、`scripts/fix_parity_forward_decls.py --check` |
| 收集产物 | `actions/upload-artifact@v4` → 工件 `MT-Agent-replica-<run_number>`（保留 30 天） |
| **回传 .tipa** | 把 `build/MT-Agent-replica.tipa` 推到 **`dist` 分支**（单提交孤分支 + force push，见下） |

## 3. 取回 .tipa（不需要 gh / token）

`dist` 分支是一个孤分支（orphan），每次构建只保留一个提交，仓库体积不随构建次数线性膨胀。

```bash
git fetch origin dist
git checkout dist -- MT-Agent-replica.tipa   # 或：git show dist:MT-Agent-replica.tipa > out.tipa
```

- 说明：仓库为 **私有**，Actions 工件（artifact）下载需要登录态；`dist` 分支走 git 协议，
  任何已有仓库读写权限的客户端都能直接取，服务器上也能一条命令拿回来。
- 或者直接在 GitHub 网页：仓库 → Actions → 选中运行 → 页面底部 **Artifacts** 下载 zip。

## 4. 安装到设备

产物是 **TrollStore 用的 .tipa**（`cryptid=0`、无 provisioning profile，entitlements 11 项对齐原包）。

1. 用 TrollStore 打开 `.tipa` 直接安装；
2. 首次启动后在 **设置 → 运行时环境** 里安装 codex CLI 运行时（走 runtime-manifest + gh-proxy 下载、校验、签名、安装五阶段）；
3. 在 **设置 → Provider** 里填 `base_url` / API Key（默认 `wire_api=responses`，与原包一致）。

## 5. 本地（Windows）可做的校验

没有 Mac 也能跑编译门禁与一致性校验：

```powershell
# 全量编译检查（需要 .toolchain 里的 clang + iPhoneOS SDK）
& _cakit\check_compile.ps1 -All -ErrorsOnly      # 期望：编译失败文件数 = 0 / 163

# 工程一致性 / 字面量 / 方法覆盖
python verify\verify_parity.py
python verify\verify_literals.py
python verify\verify_method_coverage.py
```
