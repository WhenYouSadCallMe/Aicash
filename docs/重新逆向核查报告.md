# 重新逆向核查报告（REA/IDA 对照原包二进制）

本次用 IDA（idalib, arm64 原包主程序 `CodexApp`，7,087,072 字节）对原包做了**方法面级**重新逆向，
并与复刻源码逐选择器对照。之前的"97.3% 方法覆盖"存在**统计口径问题**，本报告给出真实数字。

## 1. 之前的覆盖度为什么虚高

`verify_method_coverage.py` 旧版把 `.h` 里的**声明**也算"命中"。
`CACodexEngine.h` 里有 349 行反编译来的声明（`- (id)steerPrompt:(id)arg1 ...`），
它们让文本覆盖率到 97.3%，但 `.m` 里根本没有实现体。

已把门禁改为**双轨统计**（`SPEC/method_coverage.json` 现在有两套数字）：

| 口径 | 数值 | 含义 |
|---|---|---|
| 文本命中（旧口径） | 97.3% (5039/5180) | 选择器名在源码里出现过（含 .h 声明） |
| **实现体命中（新口径）** | **75.2% (3897/5180)** | 选择器在 .m 里有实现痕迹 |

## 3. 引擎协议面（app-server JSON-RPC）的真实覆盖

原包二进制里可见的 35 个方法/通知，复刻**消费或发送**的只有 9 个：

已实现：`thread/resume`、`turn/start`、`turn/interrupt`、`turn/usage`（委托转发）、
`item/tool/requestUserInput`（委托转发）、`app-server.invalidated`、
`mcp/servers/status`、`turn/completed|failed|aborted`（回合终止判定）、
`item/commandExecution/outputDelta`、reasoning/agent_message delta（宽松 containsString 匹配）。

**未实现（26 个）**，按影响排序：

| 缺失 | 用户可见影响 |
|---|---|
| `item/tool/requestUserInput` 的 **answers 回传**（原包 `sendResult:forRequestID:`） | 计划审批/问题卡点了以后 **答案送不回 codex**，回合会挂住 —— 这是当前最严重的一处 |
| `turn/steer`（含 queued steer） | 回合进行中追加输入无效 |
| `thread/resume` 之外的 `thread/read` / `thread/delete` / `thread/turns` | 历史会话恢复/删除走的是我们自己的 index.json，与 codex 端状态可能脱节 |
| `thread/tokenUsage/updated` / `account/rateLimits/read` | 侧栏「主限额/次限额」读的是本地 rate-limits.json 快照，不刷新 |
| `model/list` / `model/pricing` | 模型目录/价格不会从服务端刷新（有本地兜底） |
| `item/mcpToolCall`、`mcpServerStatus/list` 主动查询 | MCP 工具卡显示不完整 |
| `thread/shellCommand`、`thread/compacted`、`thread/settings` | 压缩上下文/远端 shell 无 |
| `turn/plan/updated` | 计划卡更新不实时 |

## 6. 结论：复刻得对不对

- **结构/权限/资源/文案层：对。**包条目、plist、entitlements、符号链接、全部 87 条截图文案、
  设置页四段结构，全部机器可验一致。
- **UI 骨架层：对。**截图 7 屏的可视元素与层级已逐屏对齐（两轮）。
- **引擎/数据层：不完全。**文本覆盖 97.3% 是虚的，真实实现体覆盖 75.2%；
  其中**直接影响可用性**的缺口是 `requestUserInput` 的应答回传（计划卡会挂）、
  `turn/steer`（回合中插话）、`thread/read|delete|turns`（历史与 codex 端脱节）、
  rate-limits/model-list 的主动刷新。

## 7. 建议的修复优先级（如要继续补齐）

1. `CAAppServerSession` 增加 `sendResult:forRequestID:` + 在 engine 的
   plan/decision completion 里把 answers 回传（否则计划卡是死路）；
2. `turn/steer`（排队 + expectedTurn 匹配）；
3. `thread/read` / `thread/delete` / `thread/turns` 接到侧栏历史操作；
4. `thread/tokenUsage/updated` → 上下文 0% 实时化；`account/rateLimits/read` 主动刷新；
5. `model/list` 刷新（设置页模型价格页保持本地兜底）；
6. 会话迁移 journal（`CAConversationMigration`）：工作区切换时的记录搬移原子性。

——以上 1、2 做完，"聊天能正常用"；3-6 做完，行为与原包等价（除 Theos/Python 安装的
长尾子步骤，那两块原包自己也是按需触发的）。
