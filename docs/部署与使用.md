# 部署与使用（复刻版）

本文件面向"拿到复刻包之后怎么装、怎么用、怎么排障"，与 `SPEC/复刻规格书.md`（行为契约）配套。

## 1. 安装（与原包同路径）

复刻包需通过 **TrollStore**（或等价的支持 `platform-application` 特权签名的安装器）安装：

1. 把 `build/MT-Agent-replica.tipa` 传到设备（AirDrop / 文件 App / Filza / ssh 均可）。
2. 用 TrollStore 打开并安装（TrollStore 会用包内 entitlements 做 adhoc/CoreTrust 签名）。
3. 安装后**不要**用普通签名工具重签：普通签名会剥离 `platform-application`、`no-sandbox`、`AppDataContainers` 等特权，工具会退化为沙箱应用（表现为：无法写 `/var/mobile/Documents`、无法启动 runtime、shell 探针 `DOCS_WRITE=0`）。

自检（安装后首次打开会写日志）：

```
/var/mobile/Library/Application Support/CodexApp/Logs/CodexApp.log
```

日志应包含：`Codex started`、`environment profile kind=… jailbreak=… trollstore=…`、`internal MCP bridge listening 127.0.0.1:27018/mcp`。

## 2. 首次使用流程

1. **工作区**：默认工作目录 `/var/mobile/Documents`（`CodexDocumentsWorkspaceDisplayName` 可改名）。
2. **运行时**：进入诊断页 → 运行时管理 → 安装 Codex Runtime（从 `CARuntimeManifestURL` 拉清单，走 GitHub 直连或 `gh-proxy.org` / `ghproxy.net` 代理，校验 `archive_sha256` 后用 `Helpers/codex-sign` 重签并安装到 `RuntimeDownloads/<runtime_id>`）。
3. **登录（三选一）**：
   - 账号登录：`codex login`（浏览器 OAuth，回调 `auth.openai.com/oauth/authorize`）
   - 设备码：`codex login --device-auth`
   - API Key / Access Token：`codex login --with-api-key` / `--with-access-token`
4. **第三方 provider**（可选）：设置页选择第三方 provider → 填 `base_url` + API Key。
   - 密钥落盘位置：`/var/mobile/Library/Application Support/CodexApp/CodexApp/Provider/api-key`（目录 0700 / 文件 0600）
   - 注入方式：`CODEX_CUSTOM_API_KEY` 环境变量 + `-c model_providers.custom={…}`（`wire_api="responses"`）
5. **分享扩展**：任意 App 分享图片/文件/视频 → "MT 智能体" → 写入 `group.wiki.qaq.codexapp` 的 `CodexAttachments/Inbox`，主 App 启动时读取。

## 3. 排障对照表

| 现象 | 排查 |
|---|---|
| 打不开 / 启动即退 | 是否用普通签名安装（特权丢失）；看 `CodexApp.log` 最后一行 |
| shell 相关功能全废 | `Helpers/` 下的符号链接是否还在（tar/解压工具可能破坏符号链接）；`Helpers/bash` 应指向 `../CodexApp` |
| 无法下载运行时 | 网络可达性（GitHub / 两个代理前缀）；`SHA256SUMS` 是否与 `archive_sha256` 一致；看 `RUNTIME` 分类日志 |
| codex 找不到 | `resolveCodexExecutable` 顺序：`RuntimeDownloads/codex/bin/codex` → `/var/jb/usr/bin/codex` → `/var/jb/usr/local/bin/codex` → `/usr/libexec/codex/codex` → `/usr/bin/codex` → `/usr/local/bin/codex` |
| 聊天一直"app-server not ready" | 常驻 app-server 崩溃（`app-server exited status=%d`）；会自动回退 `exec --json` 路径 |
| 内部 MCP 工具不出现 | `127.0.0.1:27018/mcp` 未监听或端口被占用；日志 `internal CodexApp MCP bridge is unavailable` |
| 心跳/远端开关不生效 | `Supabase` 可达性；看 `Codex heartbeat failed count=%ld/%ld` |
| 后台长任务被杀 | iOS 后台限制；保活依赖 `UIBackgroundModes=audio` + 静音音频 + `beginBackgroundTask` 续期，被系统重置后会自动重建 |

## 4. 常用路径速查

```
/var/mobile/Documents                                  工作区
/var/mobile/Documents/.codex                           CODEX_HOME（auth.json / config.toml / sessions）
/var/mobile/Documents/.codex/log                       CLI 日志
/var/mobile/Documents/CodexHelpers                     helper 落点
/var/mobile/Documents/.mt-device-group-id-v1           设备组 ID（心跳用）
/var/mobile/Library/Application Support/CodexApp      App 数据（含 CodexApp/Provider/api-key）
/var/mobile/Library/Application Support/CodexApp/RuntimeDownloads   运行时与清单缓存
/var/mobile/Library/Caches/CodexApp/Diagnostics       诊断快照
/var/mobile/Library/Preferences/wiki.qaq.codexapp.plist  defaults
```

## 5. 与原包并存时的注意点

* 两者 bundle id 相同（`wiki.qaq.codexapp`），**不能同时安装**；安装复刻包会覆盖原包（数据目录共用，`auth.json`、会话、密钥文件都会沿用）。
* 覆盖安装后首次启动会自动清理遗留位置（`Codex-mt`、`CodexHelpers` 旧目录、`/var/mobile/Documents/.codex/log` 旧日志）。
