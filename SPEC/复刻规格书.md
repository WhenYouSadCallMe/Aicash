## 3. 远端契约（CARemoteOperations）

- Base：`https://bctwtbuvphdwbnlbprav.supabase.co`
- 头：`apikey: <anon JWT>`、`Authorization: Bearer <同一 anon JWT>`、`Content-Type: application/json`、`User-Agent: CodexApp/1.0`
- 超时 12s；session 为 ephemeral（不落 cookie/缓存）
- anon JWT payload：`{"iss":"supabase","ref":"bctwtbuvphdwbnlbprav","role":"anon","iat":1769755966,"exp":2085331966}`（硬编码）

| 用途 | 方法+路径 | 附加 |
|---|---|---|
| 策略拉取 | `GET /rest/v1/risk_control_config?id=eq.1&select=feature_flags,log_switches,max_heartbeat_fail_count,updated_at` | — |
| 心跳 | `POST /rest/v1/heartbeats?on_conflict=anonymous_id` | `Prefer: resolution=merge-duplicates,return=minimal` |

心跳 body（8 字段，顺序即原包构造顺序）：

```json
{
  "anonymous_id":   "<UUID，缺省为空串>",
  "device_group_id":"<UUID，来自 /var/mobile/Documents/.mt-device-group-id-v1>",
  "last_seen":      "<ISO8601 含毫秒>",
```

## 4. codex CLI 契约（CACodexEngine）

**常驻会话**：`codex app-server --stdio`（JSON-RPC over stdio）。

## 5. 密钥与凭据处理

**存储：文件（不是 Keychain）**
- 读：`fileExistsAtPath:keyPath` → `stringWithContentsOfFile:encoding:error:` → 去首尾空白
- 写：`createDirectoryAtPath:attributes:{NSFilePosixPermissions:0700}` 后原子写文件，落地 `chmod 0600`
- 位置：`<Application Support>/CodexApp/Provider/api-key`（目录 `CodexApp/Provider`、文件名 `api-key`、临时名前缀 `.api-key-`）

**Keychain：只读旧值 + 只删（原二进制无 `SecItemAdd`/`SecItemUpdate`）**
- `SecItemCopyMatching`（`kSecClassGenericPassword` + `kSecReturnData`）用于迁移旧值
- `SecItemDelete`：`service=CodexApp.CustomProvider, account=APIKey`；另清 `service=CodexApp/Provider, account=api-key`
- 日志：`provider credential read/save/migration failed code=%ld`、`legacy provider credential cleanup failed`

**凭据消费**：仅注入到本地 codex 进程（env `CODEX_CUSTOM_API_KEY` + `model_providers.custom` 配置）；账号态（`auth.json`）由 `CACodexMetadataReader` 本地解析展示（`tokens.id_token` 的 `sub/preferred_username/given_name/picture`）。

**日志脱敏正则**（原文照抄）：

```
(?i)Bearer\s+[A-Za-z0-9._~+/-]+=*                                  → "Bearer <redacted>"
sk-[A-Za-z0-9_-]{8,}                                               → "<redacted-key>"
(?i)(access[_ -]?token|api[_ -]?key|authorization)(\s*[:=]\s*)([^\s,;]+) → "$1$2<redacted>"
```

## 8. 运行时下载 / 完整性 / 签名链

1. 清单：`CARuntimeManifestURL`（raw.githubusercontent，susu123oss/CodexApp-Runtime）→ 缓存 `RuntimeDownloads/runtime-manifest.json`；仅接受 https（`isSafeHTTPSURL:`）
2. 条目字段：`runtime_id / display_name / summary / handler / group / version / revision / archive_url / archive_sha256 / download_size / expanded_size / order / optional / install`
3. 下载候选：GitHub 直链 + 代理前缀 `https://gh-proxy.org/`、`https://ghproxy.net/`
4. 完整性：`archive_sha256` 与 release `SHA256SUMS`（`…/releases/download/<tag>/SHA256SUMS`）双通道校验后解包
5. 解包：tar.gz（zlib）与 deb（ar → data.tar.*）；tar 支持 `0/5/2/1` 类型与 GNU `L/K`、PAX；路径逃逸由 `safeRelativePath:` 拦截
6. 签名：`Helpers/codex-sign --adhoc-only --entitlements <plist> <binaries…>`（CoreTrust 绕过路径，`--entitlements` 为上述模板）
7. 安装：`RuntimeDownloads/<runtime_id>/…` + `manifest.json`（revision/version/installed_at）；缓存清理 `pruneRuntimeDownloadCacheExceptVersion:`
8. 执行环境变量：Python → `PYTHONHOME/PYTHONPATH`；Theos → `CA_THEOS_{RUNTIME,SDKROOT,MAKE,EMBEDDED,PACKAGE_MODE,SEQUENCE_DIR,…}`；逆向工具 → `R2_PREFIX`、`CA_REVERSE_TOOLS_STAGING`

## 9. 多调用（multi-call）分派表

| `argv[0]` | 行为 |
|---|---|
| `CodexApp`（无后缀） | 启动 UI（`UIApplicationMain` + `CAAppDelegate`） |
| `bash` / `sh` | `exec Helpers/bash.real`（把自身当 bash） |
| `bash-codex` | 调 codex CLI（无 codex 时退化为 `bash -lc`） |
| `codex-code-mode-host` | 常驻，等待内部 MCP 桥（27018） |
| `ca-filetool` | 工具集主入口（下表的调用名分派） |
| `theos-helper` | `upper` / `schema-key` / `sort-versions` / `fakeroot -p -r -c` / `verify-deb` / `assemble-deb` / `build-deb-forkless` |
| `cat tee ls mkdir rm touch cp mv chmod ln stat uname which basename dirname readlink realpath du wc head tail grep sed sort uniq nl find xxd od tar sysctl date` | 对应工具实现（支持原包同款开关：`-l -a -h -R -p -c -n -r -f -i -v -F -e -k -C -z -J -x --json=…`） |

`theos-helper fakeroot` 用于 Theos 打包（无 fork 环境下的伪 root）；`verify-deb` 解析 ar 成员（`debian-binary`/`control.tar.*`/`data.tar.*`）；`assemble-deb` 组装 deb 并写入 `DEBIAN/control`。

## 11. 复刻未覆盖 / 需实测补齐项

1. **UI 细节**：原包 UI 由数百个 `CA*ViewController/Cell/View` 组成（符号表见 `SPEC/assets/objc_api_map.json`）。复刻按符号名重建主要界面，排版/动效为近似。

3. **`Helpers/codex-sign`、`Helpers/bash.real`**：直接复用原包二进制（重建需上游源码）。
4. **xz/zstd 压缩的 deb**：复刻实现 gz；xz/zstd 需额外库，当前依赖 `theos-helper`（原包 ca-filetool 内含 xz 支持）。
5. **模型目录/价格同步的字段级细节**：`CAModelPricingManager` 为按原包 URL 与键名重建的近似实现。
6. 语言/本地化字符串：以 `SPEC/assets/strings_full.txt`（23,686 条原文）为准，可按需精确替换。
